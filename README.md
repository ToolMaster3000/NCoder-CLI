# NCoder-CLI
A local, on-device chat CLI for Android/Termux running Nanbeige4.1-3B-heretic via llama.cpp, with a grammar-constrained agentic tool-calling loop (web search, arbitrary HTTP requests, sandboxed file access, Python execution, keyword notes search, and Termux:API integration), built for 4GB+ RAM Android devices (Xiaomi, Samsung, Huawei, and similar).
